# 🎯 РЕШЕНИЕ ПРОБЛЕМЫ: Белый экран и пути /public/

## 📋 Ваши проблемы

1. ❌ Белый экран при открытии сайта
2. ❌ URL выглядит как `http://onclik.ru/public/index.html`
3. ❌ Должно быть: `http://onclik.ru/`

## ✅ БЫСТРОЕ РЕШЕНИЕ (5 минут)

### Шаг 1: Откройте файловый менеджер хостинга

Зайдите в панель управления хостингом → Файловый менеджер

### Шаг 2: Переместите файлы из /public/ в корень

**Найдите папку `/public/`** (обычно в `public_html/public/` или `www/public/`)

**Переместите ВСЕ файлы в корень домена:**

```
БЫЛО:                          СТАЛО:
public/                        public_html/ (или www/)
├── index.html                 ├── index.html          ✅
├── .htaccess                  ├── .htaccess           ✅
├── install.php                ├── install.php         ✅
├── assets/                    ├── assets/             ✅
│   ├── index-BAHadLUP.css     │   ├── index-BAHadLUP.css
│   └── index-BapUzI4H.js      │   └── index-BapUzI4H.js
└── api/                       └── api/                ✅
    └── index.php                  └── index.php
```

**Как переместить:**
1. Откройте папку `/public/`
2. Выделите все файлы (Ctrl+A)
3. Правый клик → "Переместить" (Move)
4. Перейдите в корень домена
5. Правый клик → "Вставить" (Paste)

### Шаг 3: Удалите папку /public/

После перемещения файлов удалите пустую папку `/public/`.

### Шаг 4: Проверьте результат

Откройте в браузере:
```
http://onclik.ru/
```

**НЕ:**
```
http://onclik.ru/public/index.html  ❌
```

**А:**
```
http://onclik.ru/  ✅
```

Должен открыться лендинг!

### Шаг 5: Установите CRM

1. Откройте: `http://onclik.ru/install.php`
2. Заполните форму (данные БД, email, пароль)
3. Нажмите "Установить CRM"
4. **УДАЛИТЕ** файл `install.php` после установки!

## 🔍 Если не помогло

### Проверка 1: Структура файлов

Зайдите в файловый менеджер и убедитесь, что:

✅ **Правильно:**
```
public_html/
├── index.html
├── .htaccess
├── install.php
├── assets/
│   ├── index-BAHadLUP.css
│   └── index-BapUzI4H.js
└── api/
    └── index.php
```

❌ **Неправильно:**
```
public_html/
└── public/              ← НЕ ДОЛЖНО БЫТЬ!
    ├── index.html
    └── ...
```

### Проверка 2: Прямой доступ к файлам

Откройте в браузере:
```
http://onclik.ru/assets/index-BAHadLUP.css
```

- ✅ Должен открыться CSS код
- ❌ Если 404 - файлы не перемещены правильно

### Проверка 3: Консоль браузера

1. Откройте `http://onclik.ru/`
2. Нажмите `F12`
3. Вкладка **Console**
4. Посмотрите ошибки

**Возможные ошибки:**

❌ `Failed to load resource: 404 Not Found` для `/assets/...`
- **Решение:** Файлы не перемещены в корень

❌ `Uncaught SyntaxError: Unexpected token '<'`
- **Решение:** JavaScript файл не загружен

### Проверка 4: Вкладка Network

1. Откройте консоль (`F12`)
2. Вкладка **Network**
3. Обновите страницу (`F5`)
4. Найдите файлы:
   - `index-BAHadLUP.css` - статус **200 OK** ✅
   - `index-BapUzI4H.js` - статус **200 OK** ✅

## 💡 Почему это работает?

**Проблема:** Файлы загружены в `/public/`, поэтому:
- URL содержит `/public/index.html`
- Пути к файлам не работают (ожидают `/assets/...`, а не `/public/assets/...`)
- Белый экран, потому что CSS и JS не загружаются

**Решение:** Переместить файлы в корень домена:
- URL становится `http://onclik.ru/`
- Пути работают правильно (`/assets/...`)
- CSS и JS загружаются
- Сайт отображается корректно
