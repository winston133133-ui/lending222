## 📋 Пошаговая установка

### Шаг 1: Сборка проекта (если ещё не собрано)

Если вы работаете локально:
```bash
npm install
npm run build
```

Если у вас нет Node.js, используйте готовые файлы из папки `dist/`.

### Шаг 2: Загрузка файлов на хостинг

Загрузите **ВСЕ** файлы из папки `dist/` в корень вашего сайта через FTP или файловый менеджер хостинга:

- ✅ `index.html`
- ✅ `.htaccess`
- ✅ Папка `assets/` (со всем содержимым)
- ✅ Папка `api/` (из `public/api/`)
- ✅ `install.php` (из `public/`)

**Структура на хостинге должна быть:**
```
ваш-сайт.ru/
├── index.html
├── .htaccess
├── install.php
├── assets/
│   ├── index-*.js
│   └── index-*.css
└── api/
    └── index.php
```

### Шаг 3: Создание базы данных

1. Зайдите в панель управления хостингом
2. Создайте базу данных MySQL:
   - Имя БД: например `party_crm`
   - Пользователь: создайте нового или используйте существующего
   - Пароль: запомните его
   - Хост: обычно `localhost`

### Шаг 4: Запуск установки

1. Откройте в браузере: `https://ваш-сайт.ru/install.php`
2. Заполните форму:
   - **Хост базы данных**: `localhost` (или то, что указал хостинг)
   - **Имя базы данных**: `party_crm` (или ваше имя БД)
   - **Пользователь БД**: ваш пользователь MySQL
   - **Пароль БД**: ваш пароль MySQL
   - **Email администратора**: ваш email для входа в CRM
   - **Пароль администратора**: придумайте надёжный пароль

3. Нажмите **"Установить CRM"**

### Шаг 5: Завершение установки

1. ✅ После успешной установки **ОБЯЗАТЕЛЬНО УДАЛИТЕ** файл `install.php` с сервера!
2. Откройте сайт: `https://ваш-сайт.ru/`
3. Должен открыться лендинг
4. Для входа в админку: `https://ваш-сайт.ru/#/login`
5. Используйте email и пароль, которые вы указали при установке

## ⚠️ Решение проблем

### Проблема: Лендинг не открывается (белый экран)

**Причина 1:** Не загружены все файлы
**Решение:** Убедитесь, что загрузили ВСЕ файлы из `dist/`, включая папку `assets/`

**Причина 2:** Неправильные пути к файлам
**Решение:** Проверьте, что в `index.html` пути начинаются с `./assets/...`, а не с `/assets/...`

**Причина 3:** Не загружен `.htaccess`
**Решение:** Загрузите файл `.htaccess` в корень сайта

### Проблема: Ошибка 404 при обновлении страницы

**Причина:** Не работает SPA fallback
**Решение:** Убедитесь, что загружен `.htaccess` с правилом:
```apache
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_URI} !^/api/
RewriteRule ^(.*)$ /index.html [L]
```

### Проблема: API не работает (ошибка 500)

**Причина 1:** Не создан файл `api/config.php`
**Решение:** Запустите `install.php` заново

**Причина 2:** Неправильные права доступа
**Решение:** Установите права 755 на папку `api/` и 644 на файлы

**Причина 3:** PHP версия ниже 7.4
**Решение:** Обновите PHP на хостинге до версии 7.4 или выше

### Проблема: Не удаётся подключиться к базе данных

**Решение:**
1. Проверьте данные БД в файле `api/config.php`
2. Убедитесь, что база данных создана
3. Проверьте, что пользователь имеет права на эту БД
4. Попробуйте запустить `install.php` заново

### Проблема: Изображения не загружаются

**Решение:**
1. Проверьте права на папку для загрузки (755)
2. Увеличьте `upload_max_filesize` в `php.ini`
3. Проверьте доступное место на диске
