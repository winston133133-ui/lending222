# 🚀 Правильная установка на хостинг onclik.ru

## ❌ Ваша текущая проблема

Файлы загружены в папку `/public/`, поэтому URL выглядит как:
```
http://onclik.ru/public/index.html
```

Это **НЕПРАВИЛЬНО**! Должно быть просто:
```
http://onclik.ru/
```

## ✅ Правильная структура на хостинге

Все файлы из папки `dist/` должны быть загружены **В КОРЕНЬ ДОМЕНА**, а не в `/public/`:

```
onclik.ru/                    ← КОРЕНЬ ДОМЕНА
├── index.html                ✅ В корне!
├── .htaccess                 ✅ В корне!
├── install.php               ✅ В корне!
├── assets/                   ✅ Папка в корне!
│   ├── index-BAHadLUP.css
│   └── index-BapUzI4H.js
└── api/                      ✅ Папка в корне!
    └── index.php
```

## 📋 Пошаговая инструкция

### Шаг 1: Очистите хостинг

Удалите все файлы из папки `/public/` (или из корня домена, если загружали туда).

### Шаг 2: Загрузите файлы ПРАВИЛЬНО

**ВАЖНО:** Загружайте файлы **ИЗ ПАПКИ `dist/`**, а не из корня проекта!

#### Что загрузить из `dist/`:

```
dist/
├── index.html              → загрузить В КОРЕНЬ ДОМЕНА
├── .htaccess               → загрузить В КОРЕНЬ ДОМЕНА
└── assets/                 → загрузить В КОРЕНЬ ДОМЕНА (папку целиком!)
    ├── index-BAHadLUP.css
    └── index-BapUzI4H.js
```

#### Что загрузить из `public/`:

```
public/
├── install.php             → загрузить В КОРЕНЬ ДОМЕНА
└── api/                    → загрузить В КОРЕНЬ ДОМЕНА (папку целиком!)
    └── index.php
```

### Шаг 3: Проверьте структуру

Зайдите в файловый менеджер хостинга и убедитесь, что структура такая:

```
Корень домена (обычно public_html/ или www/)
├── index.html
├── .htaccess
├── install.php
├── assets/
│   ├── index-BAHadLUP.css
│   └── index-BapUzI4H.js
└── api/
    └── index.php
```

**НЕ должно быть вложенных папок вроде:**
```
❌ public_html/public/index.html
❌ public_html/dist/index.html
```

### Шаг 4: Установите права доступа

В файловом менеджере хостинга:

**Для файлов:** `644`
**Для папок:** `755`

Как установить:
1. Правый клик на файле/папке
2. "Атрибуты" или "Permissions" или "Свойства"
3. Установите права

### Шаг 5: Запустите установку

Откройте в браузере:
```
http://onclik.ru/install.php
```

**НЕ** `http://onclik.ru/public/install.php`!

Заполните форму:
- Хост БД: `localhost`
- Имя БД: `onclik_crm` (или создайте в панели хостинга)
- Пользователь БД: ваш пользователь MySQL
- Пароль БД: ваш пароль MySQL
- Email администратора: ваш email
- Пароль администратора: придумайте надежный пароль

Нажмите "Установить CRM"

### Шаг 6: Удалите install.php

**ОБЯЗАТЕЛЬНО!** После успешной установки удалите файл `install.php` с хостинга!

### Шаг 7: Проверьте сайт

Откройте:
```
http://onclik.ru/
```

Должен открыться лендинг со стилями!

## 🔍 Если все еще белый экран

### Проверка 1: Консоль браузера

1. Откройте сайт
2. Нажмите `F12`
3. Перейдите на вкладку **Console**
4. Посмотрите ошибки

**Возможные ошибки:**

❌ `Failed to load resource: 404 Not Found` для `/assets/...`
- **Причина:** Файлы не загружены в корень
- **Решение:** Проверьте, что папка `assets/` находится в корне домена

❌ `Uncaught SyntaxError: Unexpected token '<'`
- **Причина:** JavaScript файл не загружен
- **Решение:** Проверьте путь к JS файлу

### Проверка 2: Прямой доступ к файлам

Откройте в браузере:
```
http://onclik.ru/assets/index-BAHadLUP.css
```

Должен открыться CSS код. Если 404 - файлы не загружены правильно.

### Проверка 3: Просмотр исходного кода

1. Откройте сайт
2. Правый клик → "Просмотр кода страницы"
3. Найдите строки:
```html
<script type="module" crossorigin src="/assets/index-BapUzI4H.js"></script>
<link rel="stylesheet" crossorigin href="/assets/index-BAHadLUP.css">
```

Пути должны начинаться с `/assets/`, а не с `./assets/` или `/public/assets/`.

## 🎯 Альтернативное решение (если не можете загрузить в корень)

Если ваш хостинг не позволяет загружать файлы в корень, можно настроить `.htaccess` для работы из папки `/public/`:

### Вариант 1: Настройка DocumentRoot

В панели управления хостинга:
1. Найдите настройки домена
2. Измените DocumentRoot на `/public/`
3. Сохраните

### Вариант 2: .htaccess в корне

Создайте `.htaccess` в **корне домена** (не в `/public/`):

```apache
RewriteEngine On
RewriteBase /
RewriteRule ^(.*)$ public/$1 [L]
```

Но это **НЕ РЕКОМЕНДУЕТСЯ**. Лучше загрузить файлы в корень.

```javascript
// Проверить загрузку CSS

```

Должно вывести:
```
CSS: 200
JS: 200
```

Если 404 - файлы не загружены правильно.
