# 🔧 Исправление проблемы со стилями

## ❌ Проблема
Стили не применяются на лендинге и в админке после загрузки на хостинг.

## ✅ Решение

### Шаг 1: Проверьте структуру файлов на хостинге

Убедитесь, что структура такая:

```
ваш-сайт.ru/
├── index.html                    ✅ Обязательно в корне!
├── .htaccess                     ✅ Обязательно в корне!
├── install.php                   ✅ В корне (удалить после установки)
├── assets/                       ✅ Папка должна быть в корне!
│   ├── index-BAHadLUP.css        ✅ CSS файл (64.59 kB)
│   └── index-BapUzI4H.js         ✅ JS файл (416.48 kB)
└── api/                          ✅ Папка должна быть в корне!
    └── index.php                 ✅ API файл
```

**ВАЖНО:** Папка `assets/` должна быть в КОРНЕ сайта, а не внутри другой папки!

### Шаг 2: Проверьте содержимое index.html

Откройте файл `index.html` на хостинге и убедитесь, что строки 24-25 выглядят так:

```html
<script type="module" crossorigin src="./assets/index-BapUzI4H.js"></script>
<link rel="stylesheet" crossorigin href="./assets/index-BAHadLUP.css">
```

**Пути должны начинаться с `./assets/`**, а не с `/assets/` или `assets/`.

### Шаг 3: Проверьте .htaccess

Убедитесь, что файл `.htaccess` загружен в корень сайта и содержит:

```apache
RewriteEngine On

# API routing
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^api/(.*)$ api/index.php?path=$1 [QSA,L]

# SPA fallback
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_URI} !^/api/
RewriteRule ^(.*)$ /index.html [L]
```

### Шаг 4: Проверьте права доступа

Установите права на файлы и папки:

```bash
# Для файлов
chmod 644 index.html
chmod 644 .htaccess
chmod 644 assets/*
chmod 644 api/*

# Для папок
chmod 755 assets/
chmod 755 api/
```

### Шаг 5: Очистите кэш браузера

**Жёсткая перезагрузка:**
- Windows/Linux: `Ctrl + F5` или `Ctrl + Shift + R`
- Mac: `Cmd + Shift + R`

**Или очистите кэш вручную:**
1. Откройте настройки браузера
2. Найдите "Очистить историю просмотров"
3. Выберите "Кэшированные изображения и файлы"
4. Нажмите "Очистить"

### Шаг 6: Проверьте консоль браузера

1. Откройте сайт в браузере
2. Нажмите `F12` (откроется консоль разработчика)
3. Перейдите на вкладку **Console**
4. Обновите страницу (`F5`)
5. Посмотрите ошибки (красным цветом)

**Возможные ошибки:**

❌ `Failed to load resource: 404 Not Found`
- **Причина:** Файлы CSS/JS не найдены
- **Решение:** Проверьте, что папка `assets/` загружена в корень

❌ `Refused to apply style from...`
- **Причина:** Неправильные MIME-типы
- **Решение:** Проверьте `.htaccess` и права доступа

❌ `Uncaught SyntaxError: Unexpected token '<'`
- **Причина:** JavaScript файл не загружен
- **Решение:** Проверьте путь к JS файлу в `index.html`

### Шаг 7: Проверьте вкладку Network

1. Откройте консоль разработчика (`F12`)
2. Перейдите на вкладку **Network**
3. Обновите страницу (`F5`)
4. Найдите файлы:
   - `index-BAHadLUP.css` - должен быть статус **200 OK**
   - `index-BapUzI4H.js` - должен быть статус **200 OK**

**Если статус 404:**
- Файлы не загружены на хостинг
- Неправильные пути в `index.html`

**Если статус 200, но стили не применяются:**
- Проблема с кэшем браузера
- Проблема с `.htaccess`

### Шаг 8: Перезагрузите файлы

Если ничего не помогло, перезагрузите файлы:

1. **Удалите** все файлы с хостинга (кроме `api/config.php`)
2. **Загрузите заново** все файлы из папки `dist/`:
   - `index.html`
   - `.htaccess`
   - Папку `assets/` (со всем содержимым)
3. **Загрузите** из папки `public/`:
   - `install.php`
   - Папку `api/` (кроме `config.php`)

### Шаг 9: Проверьте URL сайта

Убедитесь, что вы открываете сайт по правильному URL:

✅ Правильно: `https://ваш-сайт.ru/`
❌ Неправильно: `https://ваш-сайт.ru/index.html`
❌ Неправильно: `file:///C:/.../index.html`

### Шаг 10: Проверьте PHP версию

Для работы API нужна PHP версия 7.4 или выше.

Проверьте версию в панели управления хостинга или создайте файл `phpinfo.php`:

```php
<?php phpinfo(); ?>
```

Откройте `https://ваш-сайт.ru/phpinfo.php` и удалите файл после проверки.

## 🎯 Быстрая проверка

Выполните эти команды в консоли браузера (`F12` → Console):

```javascript
// Проверить загрузку CSS
fetch('./assets/index-BAHadLUP.css').then(r => console.log('CSS:', r.status));

// Проверить загрузку JS
fetch('./assets/index-BapUzI4H.js').then(r => console.log('JS:', r.status));
```

Должно вывести:
```
CSS: 200
JS: 200
```
