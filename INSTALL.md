# Party CRM - Система управления агентством праздников

Полнофункциональная CRM-система для агентства по организации праздников с ростовыми куклами.

## 📋 Требования к хостингу

- **PHP** 7.4 или выше
- **MySQL** 5.7 или выше
- **Apache** с модулем mod_rewrite (или Nginx)
- **SSL сертификат** (рекомендуется)

## 🚀 Установка на хостинг

### Шаг 1: Подготовка файлов

1. Соберите проект:
```bash
npm run build
```

2. Загрузите на хостинг:
   - Содержимое папки `dist/` → в корень сайта
   - Папку `public/api/` → в корень сайта
   - Файл `public/install.php` → в корень сайта
   - Файл `public/.htaccess` → в корень сайта

### Шаг 2: Запуск установки

1. Откройте в браузере: `https://ваш-сайт.ru/install.php`
2. Заполните форму:
   - **Хост базы данных**: обычно `localhost`
   - **Имя базы данных**: например `party_crm`
   - **Пользователь БД**: ваш MySQL пользователь
   - **Пароль БД**: пароль от MySQL
   - **Email администратора**: ваш email для входа
   - **Пароль администратора**: придумайте надёжный пароль

3. Нажмите **"Установить CRM"**

### Шаг 3: Завершение

1. После успешной установки **удалите файл `install.php`** с сервера
2. Войдите в систему: `https://ваш-сайт.ru/#/login`
3. Используйте email и пароль, указанные при установке

## 📁 Структура файлов на хостинге

```
ваш-сайт.ru/
├── index.html              # Главная страница
├── assets/                 # CSS, JS файлы
│   ├── index-*.js
│   └── index-*.css
├── api/                    # Backend API
│   ├── index.php          # Основной API файл
│   └── config.php         # Конфигурация БД (создаётся при установке)
├── .htaccess              # Настройки Apache
└── install.php            # Скрипт установки (удалить после установки!)
```

## 🐛 Решение проблем

### Ошибка "Конфигурация не найдена"
Убедитесь, что файл `api/config.php` создан после установки. Если нет, запустите `install.php` повторно.

### Ошибка подключения к БД
Проверьте данные в файле `api/config.php`:
- Хост
- Имя базы данных
- Пользователь
- Пароль

### Не работает API
Убедитесь, что:
- Модуль mod_rewrite включён в Apache
- Файл `.htaccess` загружен в корень сайта
- Папка `api/` имеет права на выполнение (755)

### Изображения не загружаются
Проверьте:
- Права на папку для загрузки (755)
- Лимит upload_max_filesize в php.ini
- Доступное место на диске
