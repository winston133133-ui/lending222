# Party CRM - Система управления агентством праздников

Полнофункциональная CRM-система для агентства по организации праздников с ростовыми куклами.

## 🚀 Возможности

### Публичный сайт (Лендинг)
- ✅ Hero-секция с анимацией и изображением
- ✅ Карточки персонажей с галереей изображений
- ✅ Услуги с описаниями и ценами
- ✅ Поэтапная форма заявки (4 шага)
- ✅ Динамическое формирование доступного времени
- ✅ Кросс-товары с возможностью указания количества
- ✅ Раздел "Как заказать?" с анимацией
- ✅ Раздел "Оплата" (карта Сбербанк + безналичный расчёт)
- ✅ Условия работы и доставки (структурированные)
- ✅ Отзывы клиентов
- ✅ Галерея работ
- ✅ Контакты с кликабельными номерами
- ✅ Согласие на обработку персональных данных
- ✅ SEO-оптимизация
- ✅ Политика конфиденциальности

### CRM (Админ-панель)
- ✅ **Дашборд** - статистика, ближайшие мероприятия, выручка
- ✅ **Заявки** - Kanban-доска с 6 статусами
  - Ручное внесение предоплаты
  - Автоматический расчёт остатка
  - Прикрепление чека и отправка на email
  - Отображение кросс-товаров
  - Уведомления о новых заявках в реальном времени
  - Кликабельные номера телефонов
  - Переключение между Kanban и списком
  - Удаление заявок
- ✅ **Клиенты** - база с историей заказов
  - Статус согласия на обработку ПД
  - Кликабельные номера телефонов
- ✅ **Календарь** - визуальное отображение бронирований
  - Буфер ±30 минут между бронированиями
  - Рабочее время 06:00-23:00
- ✅ **Настройки** (12 вкладок):
  - **Персонажи** - CRUD с галереей, услугами, SEO
  - **Контакты** - телефон, WhatsApp, Telegram, Макс
  - **Тексты** - Hero, условия доставки, правила работы, логотип, иконка
  - **📋 Условия** - структурированное редактирование условий
  - **Как заказать** - шаги оформления заказа
  - **💳 Оплата** - способы оплаты (карта, безналичный расчёт)
  - **Галерея** - управление фотографиями работ
  - **Кросс-товары** - дополнительные товары с фото и ценами
  - **Уведомления** - интеграция с Telegram и Email
  - **SEO** - настройки для поисковых систем
  - **Отзывы** - управление отзывами клиентов
  - **Пользователи** - CRUD с ролями (Админ/Менеджер)

## 🛠 Технологии

- **Frontend:** React 18 + TypeScript + Vite
- **Стили:** Tailwind CSS
- **State Management:** Zustand с persist middleware
- **Роутинг:** React Router v6
- **Иконки:** Lucide React
- **Даты:** date-fns
- **Хранение:** LocalStorage (для демо) / MySQL (для продакшена)

## 📦 Установка

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build
```

### Установка на хостинг (PHP + MySQL)

1. **Соберите проект:**
   ```bash
   npm run build
   ```

2. **Загрузите файлы:**
   - Содержимое папки `dist/` → в корень сайта
   - Файл `public/install.php` → в корень сайта

3. **Запустите установку:**
   - Откройте `https://ваш-сайт.ru/install.php`
   - Введите данные для подключения к MySQL
   - Нажмите "Установить CRM"

4. **После установки:**
   - Удалите файл `install.php`
   - Войдите в CRM: `https://ваш-сайт.ru/#/login`

## 🎯 Основные функции

### Управление заявками
- **Статусы:** Новая → Обработка → Предоплата → Подтверждено → Завершено / Отменено
- **Kanban-доска** с drag-and-drop
- **Табличный вид** для быстрого обзора
- **Уведомления** о новых заявках
- **Финансы:** предоплата, остаток, общая выручка
- **Чеки:** загрузка изображений, отправка на email

### Календарь бронирований
- Визуальное отображение занятых дат
- **Буфер ±30 минут** между бронированиями
- **Рабочее время:** 06:00 - 23:00
- Автоматическая блокировка занятых слотов

### Поэтапная форма заявки
1. **Шаг 1:** Выбор персонажа и услуги
2. **Шаг 2:** Дата, время, адрес
3. **Шаг 3:** Кросс-товары (дополнительные услуги)
4. **Шаг 4:** Контакты и согласие на обработку ПД

### Кросс-товары
- Дополнительные товары (шары, фотограф и т.д.)
- Указание количества
- Автоматический пересчёт итоговой суммы
- Отображение в заявках

### Интеграция уведомлений
- **Telegram Bot** - отправка уведомлений о новых заявках
- **Email** - отправка писем с деталями заявки
- Тестовые сообщения для проверки настроек

## 🐛 Известные ограничения

- LocalStorage имеет лимит ~5-10 МБ
- Для больших объёмов данных рекомендуется MySQL
- Изображения хранятся в base64 (для демо)
- Email отправка требует настройки SMTP (для продакшена)
